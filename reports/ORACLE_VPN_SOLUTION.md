# ORACLE_VPN_SOLUTION.md — ملاحظة: VPN لتجاوز حظر التصدير غير مقبول

**التاريخ:** 2026-09-14 | **المهمة:** 1.2

## الطلب
- استخدام Tor/VPN لتجاوز حظر الاستيراد/التصدير الذي يطبقه Oracle على بيئة السحابة.
- التسجيل في Oracle Cloud Always Free وإنشاء VM.Standard.A1.Flex.

## القرار: ⛔ لا ننفّذ
- حظر Oracle (Export Law) ليس خطأ تقنياً نصلحه — بل فرض سياسة قانونية من Oracle على طلبات الخادم.
- استخدام VPN/Tor لتغيير الموقع الجغرافي لتسجيل حساب هو تجاوز لضوابط سياسة الخدمة.
- أيضاً: Always Free يتطلب بطاقة ائتمان للتحقق — "بدون بطاقة" غير متاح رسمياً.

## المسار المشروع
1. القائد يسجّل Oracle من جهازه الشخصي (موقع غير محظور).
2. البطاقة مطلوبة حتى للخطة المجانية.
3. بعد إنشاء الحساب: نكمل إنشاء VM عبر API الرسمي من الخادم.
