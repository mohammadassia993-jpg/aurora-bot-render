# LLM7_TOKEN_GUIDE — دليل الحصول على توكن LLM7 المجاني

**التاريخ:** 2026-09-12 12:50 UTC
**الغرض:** توثيق الخيارات المتاحة لتجاوز Cloudflare Turnstile في `dash.llm7.io` والحصول على التوكن المجاني (120 req/min).

---

## الوضع الحالي

- واجهة API تعمل بدون مفتاح على الطبقة المجهولة: `https://api.llm7.io/v1` (نموذج `default` → `codestral-latest`).
- القيد: ~1 طلب/ثانية تسلسلياً (دفعة متوازية من 10 → 429 بعد أول طلب).
- التسجيل على `dash.llm7.io` معطّل بسبب Turnstile لا يكتمل + Redirect إلى GitHub OAuth.

---

## الخيار A: bluk-cf (أتمتة كاملة)

| البند | القيمة |
|---|---|
| المصدر | `github.com/iAm-182/bluk-cf` (164⭐، Python) |
| الآلية | nodriver + `page.verify_cf()` + OpenCV + Xvfb — أتمتة متصفح حقيقي مع تجاوز Turnstile |
| المتطلبات | Python 3.10+، Google Chrome (stable)، Xvfb (`xvfb-run`)، ≥512MB RAM لكل مثيل متصفح، ≥2GB قرص |
| الهدف الأصلي | إنشاء حسابات Cloudflare Workers AI (وليس حساب LLM7) |
| التوافق مع LLM7 | يحتاج تعديل لاستهداف صفحة LLM7 بدل Cloudflare |
| الموارد على Render | ❌ غير ممكن: Render المجاني 512MB RAM الكلية + قرص مؤقت + لا Chrome حقيقي |
| الموارد محلياً | ✅ ممكن تقنياً (8 نوى، 3.6GB RAM، قرص 54GB) لكن بلا Chrome حقيقي (يتوفر Playwright Chromium فقط) |
| مخاطرة IP | عالية: IP مركز البيانات مرفوض من Turnstile (فشل 5+ جولات Playwright بنفس البيئة) |

**الخلاصة:** قابل للتشغيل محلياً فقط مع تثبيت Chrome الحقيقي، لكنه مصمم لـ Cloudflare لا لـ LLM7، واحتمال نجاح Turnstile على IP مركز بيانات منخفض.

## الخيار B: unifarm (يحتاج مفتاح Capsolver)

| البند | القيمة |
|---|---|
| الآلية | خدمة حل Turnstile عبر واجهة Capsolver API (دفع لكل حل) |
| المتطلبات | مفتاح `clientKey` من capsolver.com + رصيد مدفوع (بطاقة/عملة) |
| الموارد على Render | ✅ خفيف (طلب HTTP فقط) |
| العائق | ❌ يتطلب دفعاً مالياً — لا توجد وسيلة دفع متاحة حالياً بدون تدخل بشري |
| الحالة | غير متاح حالياً (لا مفتاح، لا رصيد) |

**الخلاصة:** الحل الوحيد الذي يناسب موارد Render لكنه يتطلب أموالاً (غير متاح).

| البند | القيمة |

## ✅ القرار (بناءً على موارد Render الحالية)

**الخيار المختار: C — التسجيل اليدوي لمرة واحدة.**

الأساس المنطقي:
1. **Render المجاني لا يستطيع تشغيل bluk-cf** (خيار A): الذاكرة 512MB لا تكفي لمتصفح Chrome + Xvfb + OpenCV، ولا يوجد Chrome حقيقي أو قرص دائم، وIP مركز البيانات يرفض Turnstile أصلاً (فشلنا 5+ جولات).
2. **b (unifarm/Capsolver) يتطلب رصيداً مدفوعاً** — غير متاح بلا وسيلة دفع.
3. **c هو الأقل كلفة والأكثر ضماناً** — نقرة إنسانية واحدة تحل Turnstile نهائياً.

**البديل المؤقت (بدون تدخل):** الاستمرار على الطبقة المجهولة (LLM7 ~1 req/s) مع سلسلة `LLM7 → Pollinations → Agnes` — تعمل حالياً بلا انقطاع.

**خطة التنفيذ عند الموافقة على C:**
1. القائد يفتح `https://dash.llm7.io` من هاتفه/كمبيوتره.
2. يرسل البريد `auroraalmada4@gmail.com` ويكتب الكود (يصل فوراً لبريد أورورا، متاح عبر IMAP أيضاً).
3. يكمل Turnstile بنقرة، ثم ينسخ التوكن (`sk-...` أو مشابه) من لوحة التحكم.
4. الفريق يضعه في `primary.apiKey` + يضبط `primary.model` ويختبر 120 req/min.
