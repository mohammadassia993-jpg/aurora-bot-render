# NEVER_STOP_RULE.md — قاعدة "لا تتوقف أبداً"
**Date:** 2026-09-15
**Status:** ✅ ACTIVE

## القاعدة
- **ID:** 19
- **الاسم:** `NEVER_STOP`
- **الأولوية:** CRITICAL
- **النطاق:** أي توقف الفريق > 5 دقائق = فشل حرج.

## التنفيذ
VIGIL ينفذ:
1. `alt_path` → بحث عن مسار بديل تلقائياً
2. `retry` → إعادة المحاولة مع تأخير
3. `skip_task` → تخطي المهمة الفاشلة والانتقال للتالية
4. `alert_leader` → فقط إذا فشلت الاستراتيجيات الثلاث الأولى

## النتيجة
- لا يتوقف الفريق أبداً بدون سبب تحليله VIGIL
- القائد لا يُستدعى إلا كخيار أخير
- كل توقف يُسجّل في `data/mistakes.json` تلقائياً
- حالة VIGIL في `data/vigil-state.json` تُحدّث تلقائياً
