# OPPORTUNITY_FILTER — فلترة صارمة للفرص

**التاريخ:** 2026-09-13 | **المهمة:** 1.1 — حذف أي فرصة لا تستوفي الشروط

## شروط القبول
| الشرط | الحد |
|---|---|
| مكافأة | > 0$ (N/A تُرفض) |
| الرابط | HTTP 200 (يعمل فعلياً) |
| الوصف | > 100 حرف |
| تاريخ النشر | < 30 يوماً |
| عدد العروض | < 50 |

## التشغيل الفعلي
- `src/opportunity-validator.js` — دالة `validateOpportunity()` تنفذ جميع الفحوصات الخمسة.
- تُегистّل النتائج في `task_queue` مع `validation_status: pass|fail`.
- أي فرصة تفشل أي شرط واحد تُرفض تلقائياً ولا تصل إلى القائد.
- `buildDossier()` ينشئ ملفاً كاملاً بالبيانات فقط بعد اجتياز الفلتر.

## المخرَج
✅ لا فرصة بلا قيمة تصل للقائد.
