## ما هو SiliconFlow؟

منصة صينية موحدة توفر الوصول لنماذج صينية متعددة عبر مفتاح API واحد:
- DeepSeek V3 / R1
- Qwen 2.5 (72B, 32B, Coder)
- GLM-4 (Zhipu)
- Yi-1.5 (01.AI)
- أكثر من 100 نموذج آخر

**الميزة الرئيسية:** لا حظر جغرافي — يعمل من سوريا.
