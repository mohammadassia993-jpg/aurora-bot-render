# تثبيت العمل في خلفية Huawei/EMUI

## إعداد Termux وAnyClaw
1. افتح «الإعدادات ← البطارية ← تحسين البطارية»، وغيّر وضع Termux وAnyClaw إلى «غير مُحسَّن» أو «عدم السماح بالتحسين».
2. افتح «الإعدادات ← البطارية ← تشغيل التطبيقات عند الإقلاع»، واسمح ببدء Termux وAnyClaw تلقائيًا.
3. افتح «الإعدادات ← التطبيقات ← Termux ← البطارية» واختر «غير مقيد»، ثم اسمح بالنشاط في الخلفية.
4. في مدير تطبيقات EMUI أو «App launch»، اختر Termux ثم فعّل «التشغيل التلقائي» و«التشغيل الثانوي» و«التشغيل بعد الخروج».
5. افتح قائمة المهام الحديثة، اسحب بطاقة Termux لأسفل أو اضغط أيقونة القفل حتى تظهر علامة القفل.
6. اسمح بإشعار دائم لـ Termux ولا تستخدم «تنظيف الذاكرة» أثناء عمل النظام.
7. أوقف أدوات EMUI مثل Phone Manager عن إغلاق Termux تلقائيًا واستثنِه من التنظيف العميق وإدارة الاستهلاك العالي.

## تفعيل الحماية داخل Termux
```sh
cd ~/silent-giants
bash deploy/install-runtime-protection.sh
tmux ls
curl -fsS http://127.0.0.1:8787/health
```

السكربت يفعّل `termux-wake-lock`، ويشغّل جلسة `tmux` باسم `silent-giants`، ويثبت خدمة إقلاع، بينما يعيد المشرف الداخلي تشغيل المنصة والمراقبة والنفق تلقائيًا.
