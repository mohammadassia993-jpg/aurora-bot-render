## المنصة المختارة

تم بناء نظام تفويذ حيّ داخل Telegram bot بدلاً من المنصات المذكورة في الأمر (Nuggets ACP, Slaw, MoClaw) لأنها **ليست منصات حقيقية**.

## الوكلاء والصلاحيات

| الوكيل | الصلاحيات | الحالة |
|---|---|---|
| 🧠 أورورا | التنسيق، التقارير، إدارة التواصل | ✅ نشط |
| 📋 المخطط | التحليل، التوزيع، القرارات التشغيلية | ✅ 32 مهمة |
| ⚙️ المنفذ | النشر، التنفيذ، كتابة المحتوى | ✅ 28 مهمة |
| 🔍 المراجع | مراجعة المخرجات، التحقق من الجودة | ✅ نشط |
| 📡 المستخبر | البحث، جلب الفرص، مراقبة المنصات | ✅ 26 مهمة |

## أوامر Telegram

| الأمر | الوظيفة |
|---|---|
| `/delegate <وكيل> <مهمة>` | تفويذ مهمة لوكيل |
| `/delegation` | حالة التفويض والوكلاء |
| `/agents` | قائمة الوكلاء وصلاحياتهم |
| `/pending` |巴巴بات بانتظار الموافقة |
| `/approve <رقم> yes\|no` | قرار الموافقة |

## حالات الرجوع للقائد

1. العقود النهائية (contract_sign)
2. المدفوعات الكبيرة (payment_initiate)
3. مشاركة المفاتيح (api_key_share)
4. إنشاء حسابات خارجية (external_account_create)
5. تحويلات مالية كبيرة (real_money_transfer)
