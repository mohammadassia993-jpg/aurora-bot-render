# شرح مبسط: العقد الذكي للمبتدئ (مع أمثلة)

**الفئة:** محتوى تعليمي

## العقد الذكي = "آلة بيع" على الإنترنت

تخيل آلة بيع المشروبات: تضع عملة معدنية → تحصل على مشروب دون تدخل بائع. العقد الذكي يشبه ذلك تماماً:
- **الشروط مكتوبة سلفاً** في الكود.
- **تنفيذ تلقائي** عند تحقق الشروط.
- **شفاف للجميع** على سلسلة الكتل، ولا يمكن تغييره بسهولة.

## مثال عملي بسيط

```solidity
contract Tip {
  mapping(address => uint) public balances;

  function donate() public payable {
    balances[msg.sender] += msg.value;
  }
}
```

- `donate()` يتيح لأي شخص إرسال رموز.
- الرصيد يُسجّل في `balances`.
- لا أحد (بمن فيهم المطوّر) يمكنه التلاعب بالرصيد دون شروط العقد.

## خلاصة للمبتدئ
العقد الذكي يقلّص الحاجة للوسيط ويضيف شفافية، لكنه لا يلغي الحاجة للحذر: اقرأ العقد أو اطلب مراجعته قبل أي تفاعل مالي.
