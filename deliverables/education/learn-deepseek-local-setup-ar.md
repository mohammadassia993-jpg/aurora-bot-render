# 2026-08-29 — دورة إعداد النموذج المحلي

## الهدف
تشغيل نموذج لغوي محلياً بلا مفتاح/حساب/بطاقة، لضمان استمرار الردود الذكية بالعربية.

## الخطوات
1. تثبيت ollama وتشغيل الخادم.
2. سحب النموذج: ollama pull qwen2.5:0.5b.
3. توصيل الوكلاء عبر API المحلي /api/chat.
4. ضبط AI_PREFER_LOCAL=true في الإعدادات.
5. اختبار ردود عربية والتحقق من الجودة.

## ملاحظة تنفيذية
النسخة 0.5b خفيفة وسريعة على الأجهزة المحدودة؛ للجودة الأعلى يمكن استخدام 1.5b أو 3b حسب الذاكرة.
