# دليل تفعيل المفاتيح والوصول — عمالقة الصمت

**التاريخ:** 2026-08-27 | **الإعداد:** المخطط + المستخبر + المراجع

---

## الهدف
تمكين التقديم الفعلي على المنصات (Dework / Superteam Earn / Titan) لتحقيق الدخل الفوري (~1,550$ من المخرجات الحالية + 4,400–8,000$/شهر بعد التفعيل).

---

## 1. Dework (للعمل الحر بounties)
- **المطلوب:** `DEWORK_API_TOKEN`
- **خطوات الحصول (مرة واحدة من القائد):**
  1. الدخول إلى `app.dework.xyz` بحساب العمل/المحفظة.
  2. إنشاء/اختيار Workspace (مساحة عمل).
  3. الانتقال إلى إعدادات المساحة → قسم API/التكاملات.
  4. إنشاء API Token ومنحه صلاحية قراءة/تقديم المهام.
  5. وضع القيمة في `DEWORK_API_TOKEN` داخل `.env` وإعادة التشغيل.
- **الاستخدام بعد التفعيل:** سيرسل النظام الحزم الجاهزة (3 حزم) + المهام الـ20 تلقائياً.

## 2. Superteam Earn
- **الملاحظة:** منصة Superteam Earn تعتمد على Dework، لذا تفعيل Dework يفتح الوصول لفرص Superteam أيضاً.
- **الفحص الحالي:** الواجهة تتطلب جلسة مصادقة؛ النظام لا يمكنه التسجيل ذاتياً بدون حساب.

## 3. Titan (شبكة DePIN)
- **المطلوب:** `TITAN_API_TOKEN` + `TITAN_API_URL`
- **خطوات الحصول:**
  1. التسجيل في لوحة تحكم مشروع Titan (حساب بريد).
  2. إنشاء عقدة/مشروع والحصول على التوكن من الإعدادات.
  3. وضع القيمة في `.env` وإعادة التشغيل.

## 4. مصدر الوظائف (Jobs)
- **المطلوب:** `JOB_FEED_URL` (JSON أو RSS عام للوظائف crypto/Web3).
- **اقتراح:** أي موجز عام متاح، أو يمكن تفعيل البحث اليدوي عبر لوحة التحكم.

## 5. الردود الذكية الحقيقية (اختياري)
- **الحالة:** مفاتيح Gemini/OpenRouter المتوفرة حالياً تفشل في التحقق (401/مرفوض).
- **المطلوب عند الرغبة:** مفتاح OpenRouter صالح `sk-or-...` أو Gemini صالح → يوضع في `.env` ويسحب الوضع من المحاكاة.

---

## ماذا يحدث فور توفر المفاتيح؟
1. يُعاد التشغيل (سكربت واحد: `bash deploy/termux-persistent.sh`).
2. يبدأ `syncDework/syncTitan/syncJobs` الفعلي.
3. تُرسل حزم التقديم الجاهزة للمهام المؤهلة.
4. يُرسل التقرير اليومي بالنتائج.
