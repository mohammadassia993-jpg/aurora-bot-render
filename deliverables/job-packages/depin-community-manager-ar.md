# حزمة تقديم: مدير مجتمع / تقرير لمشاريع DePIN

**الوضع:** جاهزة للإرسال عند تفعيل المفاتيح

## الملخص
يدير فريق Silent Giants مجتمعات الشبكات اللامركزية: ننشر تحديثات، نرصد الأسئلة، نعدّ تقارير دورية، ونترجم الإعلانات للعربية.

## ما نقدمه
1. تقارير أسبوعية عن صحة الشبكة ونشاط المجتمع.
2. إدارة قنوات التواصل (Telegram/Discord) بشكل احترافي.
3. ترجمة الوثائق والإعلانات إلى العربية.
4. بناء قوالب تقارير جاهزة للاستخدام المتكرر.

## عيّنة تقرير (هيكل)
```
تقرير الحالة الأسبوعي — [اسم الشبكة]
• العقد النشطة / المعطلة
• التغييرات في الاقتصاد الرمزي
• أبرز أسئلة المجتمع
• مقترحات تحسين
```
