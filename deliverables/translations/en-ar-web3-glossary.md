# قاموس مصطلحات الويب 3 (إنجليزي → عربي)

**الفئة:** ترجمة توثيقية

| المصطلح الإنجليزي | الترجمة العربية المقترحة | شرح مختصر |
|---|---|---|
| Blockchain | سلسلة الكتل / سجلّ موزّع | دفتر أستاذ رقمي لامركزي يسجّل المعاملات |
| Smart Contract | العقد الذكي | برنامج ذاتي التنفيذ على سلسلة الكتل |
| Decentralized | اللامركزي | لا يخضع لسلطة مركزية واحدة |
| DePIN | شبكات البنية التحتية المادية اللامركزية | مشاريع تنسّق بنية تحتية حقيقية عبر البلوكشين |
| Testnet | شبكة الاختبار | بيئة تجريبية بلا قيمة حقيقية للأموال |
| Mainnet | الشبكة الرئيسية | الشبكة الفعلية بأموال حقيقية |
| Wallet | المحفظة (الرقمية) | أداة لحفظ وإدارة المفاتيح والعملات |
| Private Key | المفتاح الخاص | سرّ يمنح التحكم الكامل بالحساب |
| Public Address | العنوان العام | المعرّف العام لاستقبال الأموال |
| Token | الرمز/التوكن | وحدة قيمة رقمية على سلسلة الكتل |
| Staking | التخزين/المراهنة | تجميد رموز لدعم الشبكة مقابل مكافآت |
| Airdrop | التوزيع المجاني | إرسال رموز مجانية لحاملي المحفظة |
| Yield | العائد | الربح المتحقق من الاستثمار |

## ملاحظات ترجمة
- يُفضّل إبقاء كلمة "DePIN" و"Web3" كما هي مع ترجمتها الأولى لضمان الوضوح.
- مصطلح "Staking" له مرادفات متعددة؛ اخترنا "التخزين" مع الإشارة إلى المراهنة.
