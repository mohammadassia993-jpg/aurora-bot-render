# Aurora - Silent Giants 🤖

AI-powered Telegram bot for the Silent Giants team.

## Features
- Arabic AI responses (contextual, smart)
- Team coordination (Planner, Executor, Reviewer, Scout)
- Web3 job monitoring (Dework, Titan)
- 24/7 operation
- Self-healing watchdog
- Auto-update from GitHub

## Environment Variables
Set these in HuggingFace Space Settings:
- `TELEGRAM_BOT_TOKEN` - Your Telegram bot token
- `TELEGRAM_WEBHOOK_SECRET` - Webhook secret
- `TEAM_UI_TOKEN` - Dashboard access key
- `AI_SIMULATION_MODE` - Set to "true" for local AI
- `OPENROUTER_API_KEY` - For external AI (optional)
