# DePIN Course — 5 Modules

## Module 1: What is DePIN?
Decentralized Physical Infrastructure Networks (DePIN) represent a new paradigm where physical infrastructure is owned and operated by a decentralized network of participants rather than a single corporation.

### Key Concepts:
- Physical infrastructure (storage, compute, sensors, energy)
- Token incentives for network participation
- Community governance
- Real-world utility
